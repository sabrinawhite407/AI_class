# AGENTS.md

## Project overview
This workspace is a small beginner Python learning project. The goal is to teach simple programming ideas through small standalone scripts and easy-to-read examples.

## How to work here
- Keep the code simple, readable, and beginner-friendly.
- Prefer small scripts that run with plain Python, such as `python practice.py`.
- Do not introduce frameworks, advanced libraries, or complex architecture unless the task clearly requires them.
- Favor direct examples over abstraction or clever shortcuts.
- Treat this as a teaching project, not a production app.

## Coding conventions
- Explain what each variable, operator, and built-in function is doing in plain English.
- Add comments to help beginners understand the syntax and logic.
- Use clear, descriptive names such as `meal_total`, `guest_count`, or `total_cost`.
- Keep examples focused on basics: variables, input/output, loops, conditionals, functions, and calculations.
- When explaining built-ins, use simple wording such as `ceil()` means "round upward".
- Prefer standard Python only unless a script specifically needs a data library.

## Project files
- `practice.py` and `practice2.py`: small learning exercises and demonstrations.
- `rectangle_area.py`: basic variable and arithmetic practice.
- `tipping.py`: beginner input, list, and loop practice.
- `data_practice/`: CSV-based practice files and beginner data exploration examples.

## Guardrails
- Keep scripts self-contained and easy to run.
- Do not add unnecessary setup files or package installs.
- If a task is ambiguous, prefer the simplest solution that teaches the concept clearly.
