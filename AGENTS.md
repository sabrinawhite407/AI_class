# AGENTS.md

## Project overview
This workspace is a small Python learning project focused on basic scripting and beginner programming concepts. The main goal is to keep examples simple, readable, and easy to run.

## Project conventions
- Use clear, beginner-friendly Python code.
- Every line should include at least one explanatory comment that describes both the logic and the Python syntax being used.
- Explain built-in functions in the simplest possible way. For example: "ceil() means 'round upward'" instead of using technical wording that is harder for beginners to understand.
- Prefer readable code and direct examples over advanced abstractions or unnecessary complexity.
- Keep examples easy for a beginner to follow without needing extra setup or external libraries unless the task specifically requires them.
- Focus on teaching basic programming ideas such as variables, operators, functions, and output.
